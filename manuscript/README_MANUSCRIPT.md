# Manuscript files

`Oyster_P1_CBM_Manuscript.docx/.pdf` is the submission version: the text generated by `src/build_shell_manuscript.js` after a language edit (Rubriq/AJE) that was merged selectively with `src/merge_rub_p1.py`. The edit was kept where it changed only spelling (American), hyphenation or punctuation (and no number or sign), and the original paragraph was restored (with American spelling) wherever words were added, removed or rewritten, or where symbols, tabs or equation numbers were damaged. The keyword list was reduced to six, as the submission system requires. `python build_manuscript.py --compare` therefore reports differences from the shipped file: it regenerates the text before the language edit; numbers, tables and figures are identical.
